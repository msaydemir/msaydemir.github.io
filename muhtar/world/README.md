# Muhtar — dünya bölge karoları / world region tiles

Static boundary tiles for the **Muhtar** game: the world's land surface split
into the finest available real neighbourhood / administrative boundaries.

- Source: Overture Maps `divisions` (derived from OpenStreetMap). Licence **ODbL**
  — © OpenStreetMap contributors, © Overture Maps Foundation.
- Format: see `meta.json` and `docs/DUNYA_BOLGELER.md` in the `muhtar` repository.
- Layout: `t/<lonIdx>/<latIdx>.json` geometry tiles (0.5°), `n/<lonIdx>/<latIdx>.json` neighbour tiles.

Generated by `scripts/world-regions/*` in https://github.com/msaydemir/muhtar.
