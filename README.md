# msaydemir.github.io

Public site for the mobile games' privacy policies and support contact, served by GitHub Pages at https://msaydemir.github.io/.

- `index.html` – app list + support contact
- `<app>/privacy-policy.html` – privacy policy (TR + EN) for each app; the same file lives in each app repo under `docs/privacy/`
- `HESAP_KURULUM.md` – developer account setup guide (Turkish)
- `DEVIR.md` – handoff note: repo status, next steps, and the opening prompt for a local Claude Code session

When an app's privacy policy changes, update it in the app repo first, then copy it here.
